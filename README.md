🛍️ **Sushan Store**

Sushan Store is a simple and responsive online shopping website built using HTML, CSS, and JavaScript. The project simulates a basic e-commerce platform where users can browse products, add items to the cart, and proceed to checkout.

🚀 Features
🔐 Login Page
User-friendly login interface
Clean and modern design
Email and password authentication layout
🛒 Shopping Page
Product categories display
Featured products section
Add-to-cart functionality
Responsive design for different screen sizes
💳 Checkout Page
Delivery address form
Phone number input
Multiple payment options:
Card
UPI
Cash on Delivery
Order summary with:
Product quantity management
Price calculation
Shipping and tax details
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
